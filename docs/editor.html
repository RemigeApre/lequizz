Editeur de questions

Cette page ne modifie rien en ligne toute seule : elle charge le questions.json actuel, te laisse l'editer, puis tu telecharges le resultat et tu le mets sur GitHub (glisser-deposer le fichier dans le depot, a la place de l'ancien, dans le dossier docs/). Une fois commite, le site se met a jour tout seul.

Enregistrer directement sur GitHub (optionnel)

Colle un token GitHub qui n'a le droit d'ecrire que sur ce depot, et le bouton ci-dessous committe directement docs/questions.json sans passer par le telechargement/upload manuel. Le token reste uniquement dans ton navigateur (localStorage), il n'est jamais envoye ailleurs qu'a l'API GitHub.
Cree-le sur github.com/settings/personal-access-tokens/new : type "Fine-grained", "Only select repositories" -> ce depot uniquement, permission "Contents" -> "Read and write".
